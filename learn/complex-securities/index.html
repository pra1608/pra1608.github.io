Syllabus

The default path. You can skip, reorder or go deeper at any time, for example "JUMP 6" or "go deeper on OPM backsolve".

M0Diagnostic and orientation
  • 8–10 question diagnostic on options, capital structure and accounting
  • The landscape: clients, standards, and how an engagement runs from request list to audit review
M1Option theory foundations
  • Payoff diagrams, intrinsic vs time value, put-call parity, moneyness
  • Risk-neutral valuation and why WACC doesn't belong inside an option model
  • Every security as a bundle of options
M2Black-Scholes-Merton in practice
  • Where each input comes from: underlying, strike, term, volatility (peer sets, look-back, de-levering), risk-free rate, dividends
  • Greeks for valuers, and the reviewer challenges on each input
M3Lattice models
  • Building a CRR binomial tree; early exercise and path features
  • When a lattice beats Black-Scholes: employee options, callable / puttable features, convertible bonds
M4Monte Carlo simulation
  • GBM, Cholesky correlation, path counts, convergence and standard error
  • TSR and price-hurdle awards, earnouts, Asian and barrier features
  • Making a Monte Carlo in Excel auditable
M5Capital structure and term sheets Extra depth
  • Reading a term sheet like a valuer: liquidation preferences, participation and caps, seniority, conversion, anti-dilution, dividends, redemption
  • Building the waterfall and breakpoint analysis
M6Equity allocation methods Extra depth
  • Current Value Method and when it's acceptable
  • OPM: breakpoints, call spreads, allocation per class; backsolve to the latest round and its traps
  • PWERM and hybrid methods; AICPA cheap-stock guide expectations before an IPO
M7Discounts and premiums
  • DLOM: Chaffe protective put, Finnerty, Asian put, Longstaff, restricted stock and pre-IPO studies
  • Control premiums and DLOC under ASC 820 unit of account
M8Preferred stock and convertibles
  • Redeemable, participating and convertible preferred
  • Convertible notes and SAFEs: discount, cap, MFN; host plus embedded derivative vs fair value option
  • Convertible bonds: lattice approach, credit spread calibration, bifurcation (ASC 815 / IFRS 9)
M9Warrants and other derivatives
  • Down-round features, penny warrants, dilution adjustment
  • Liability vs equity classification (ASC 480 / 815-40, IAS 32) and why it changes valuation frequency
  • SPAC warrants and earnout shares as a case study
M10Share-based compensation
  • Service, performance and market conditions under ASC 718 / IFRS 2
  • Expected term, forfeitures, private-company volatility
  • Profits interests, RSUs, PSUs with TSR modifiers; modifications and repricings
M11Contingent consideration and earnouts
  • Scenario-based vs option-pricing / Monte Carlo approaches (ASC 805 / IFRS 3)
  • Linear vs non-linear payoffs, metric risk premium, counterparty credit risk
  • Remeasurement and how it flows to the P&L
M12Calibration, reconciliation and audit review
  • Calibration at inception and each measurement date
  • Reconciling OPM / PWERM results with DCF and market approaches
  • What audit specialists check, and how to write a defensible memo
M13Capstone engagement
  • A full mock engagement, such as a Series C 409A plus ASC 718 grant valuation with a convertible note and a pending acquisition with an earnout
  • You build the model and memo; the tutor plays engagement manager and audit reviewer

Problem ladder

LevelWhat it looks like
L1 ModerateOne method, clean inputs. Compute and tie out in Excel.
L2 AppliedMessy or conflicting data; pick and justify the inputs.
L3 AdvancedTwo defensible methods disagree; recommend, reconcile, run sensitivities.
L4 EngagementClient email, deadline, auditor challenge; deliver model, memo and responses.

Each level is graded out of 10. Score 7 or more to move up.

Set it up

Pick whichever way you use Claude. Menu names can change slightly between versions.

  1. Download complex-securities-tutor.zip. Don't unzip it.
  2. In Claude, open Settings → Capabilities and find Skills. Turn on code execution if Claude asks for it.
  3. Choose Upload skill and select the zip.
  4. Start a new chat and say:
    Start the complex securities course
  1. Create a new Project in Claude, for example "Complex Securities Course".
  2. Click Copy as a prompt (button below) and paste it into the Project's instructions.
  3. Start a chat in the Project and say Start the complex securities course.
  4. At the end of each module, type TRACKER and save the block into the Project's files, so the next chat picks up where you left off.

No Projects? Paste the prompt as your first message in any Claude chat.

  1. Unzip complex-securities-tutor.zip into ~/.claude/skills/, so you have ~/.claude/skills/complex-securities-tutor/SKILL.md.
  2. Start Claude Code and say Start the complex securities course.
